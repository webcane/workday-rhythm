# Spec Delta

## Purpose

Обеспечивает заметные сигналы переходов таймера и предложение начать новый день без необходимости открывать меню приложения.

## ADDED Requirements

### Requirement: Сигнал завершения интервала
Приложение SHALL показывать заметный сигнал по центру экрана и воспроизводить звук при завершении работы и отдыха. Минимальное время показа SHALL настраиваться пользователем.

#### Scenario: Завершение работы
- **WHEN** рабочий интервал заканчивается
- **THEN** приложение показывает центральный сигнал и воспроизводит звук

#### Scenario: Настроенная длительность сигнала
- **WHEN** пользователь сохраняет минимальное время показа и затем завершается интервал
- **THEN** сигнал остаётся видимым не меньше настроенного времени

### Requirement: Утреннее предложение
В новом местном календарном дне приложение SHALL один раз предложить начать день при первом из событий — активности пользователя на Mac или наступлении 09:00. При разрешённых уведомлениях предложение SHALL появляться системным уведомлением с действием «Начать день». Таймер SHALL запускаться только по подтверждению пользователя.

#### Scenario: Активность раньше девяти
- **WHEN** первая активность на Mac в новом дне наступает в 08:30
- **THEN** показывается предложение начать день, в 09:00 оно повторно не показывается

#### Scenario: Девять часов наступило раньше активности
- **WHEN** работающий Mac достигает 09:00 без более ранней активности пользователя
- **THEN** показывается предложение начать день, таймер ожидает подтверждения

#### Scenario: Сон в девять часов
- **WHEN** Mac спит в 09:00 и просыпается позднее
- **THEN** предложение показывается после пробуждения один раз за день

#### Scenario: Приложение было закрыто
- **WHEN** пользователь впервые запускает приложение в новом дне
- **THEN** приложение предлагает начать новую программу без восстановления старой сессии

#### Scenario: Повторные события
- **WHEN** в день уже показанного предложения повторяются активность, пробуждение или запуск приложения
- **THEN** утреннее предложение повторно не показывается

### Requirement: Разрешение на утренние уведомления
При первом включении утренних уведомлений приложение SHALL запрашивать системное разрешение. При отказе приложение SHALL сохранять возможность запуска через меню и SHALL NOT показывать дополнительное всплывающее окно.

#### Scenario: Пользователь отказал в разрешении
- **WHEN** пользователь отклоняет разрешение на уведомления
- **THEN** начать день можно через меню, дополнительное окно напоминания не показывается

#### Scenario: Запуск из уведомления
- **WHEN** пользователь выбирает «Начать день» в актуальном уведомлении и работа помещается до конца дня
- **THEN** запускается новая дневная программа
