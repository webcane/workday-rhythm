# Spec Delta

## MODIFIED Requirements

### Requirement: Открытие настроек
Приложение SHALL открывать отдельное окно настроек дневной программы по команде из строки меню. Окно SHALL показывать сохранённые параметры и позволять их редактировать независимо от меню.

#### Scenario: Команда настроек
- **WHEN** пользователь выбирает «Настройки» в меню приложения
- **THEN** открывается окно с сохранённой программой, доступное независимо от меню
