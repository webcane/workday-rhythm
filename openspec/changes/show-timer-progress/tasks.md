# Задачи

## 1. Данные сессии

- [ ] 1.1 Передать длительность и актуальный остаток фактического интервала через SessionCoordinator. Проверить XCTest с управляемым временем для фокусирования, длинного отдыха, заморозки на паузе и продолжения с сохранённого остатка.
- [ ] 1.2 Подключить обновление индикатора к обработанным изменениям сессии. Проверить XCTest с подставными часами и событиями для автоматического перехода, пробуждения после отдыха и завершения дня. Проверить, что чтение снимка не порождает переходов и сигналов.

## 2. Строка меню

- [ ] 2.1 Отобразить дугу на исходном символе, отсчёт, маркеры этапов и доступное описание. Проверить XCTest для 0%, 50% и 100%, округления последней секунды и отображаемых данных всех шести этапов. Визуально проверить снимки дуги и прозрачного центра на светлом и тёмном фоне.
- [ ] 2.2 Подключить индикатор к существующему статусному элементу и обновлять отсчёт во время активного интервала. Проверить остановку обновлений на паузе, в ожидании и при выходе. Обновить описание текущей реализации в README и ручной сценарий в docs/testing.md.

## 3. Интеграционная проверка

- [ ] 3.1 Выполнить `just check`, `git diff --check` и строгую валидацию OpenSpec. Зафиксировать команды, toolchain и результаты.
- [ ] 3.2 Выполнить ручной сценарий оболочки в macOS. Проверить направление дуги и стабильность цифр, переход фокусирование → отдых → ожидание → новый фокус, паузу, пробуждение, завершение дня и повторный запуск. Проверить контраст обычной и выделенной кнопки, VoiceOver и открытие меню команд.
