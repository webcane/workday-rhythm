# Proposal

## Why

У проекта пока нет исходного кода и запускаемой точки входа. Нужен небольшой каркас, на котором можно реализовать уже описанную дневную программу, сохранив независимость правил таймера от macOS-интерфейса и хранения настроек.

## What Changes

- Создать структуру Swift-проекта для одного macOS-процесса с отдельными границами для модели программы, ядра таймера, координатора сессии, хранения настроек, системных адаптеров и представления.
- Добавить точку входа и минимальное приложение со значком в строке меню, окном настроек и командой выхода.
- Зафиксировать направленные зависимости между компонентами и способ запуска и проверки каркаса.
- Оставить бизнес-переходы, оповещения и полные настройки дневной программы для изменения `build-scheduled-menu-bar-timer`.

## Capabilities

### New Capabilities

- `application-shell`: запуск минимального macOS-приложения, доступность строки меню и окна настроек, корректный выход.

### Modified Capabilities

Нет. Основные спецификации проекта пока не опубликованы; существующее изменение `build-scheduled-menu-bar-timer` остаётся отдельным.

## Impact

Новые исходники Swift и конфигурация сборки в корне репозитория. Сторонние зависимости не требуются. Каркас использует AppKit для оболочки, Foundation для ядра и UserDefaults за границей SettingsStore. Для полной сборки macOS-приложения нужен установленный Xcode; в текущем окружении доступен Swift 6.3.2, но `xcodebuild` недоступен при активных Command Line Tools.
