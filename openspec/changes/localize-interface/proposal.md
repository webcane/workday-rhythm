# Локализация интерфейса


## Why

Интерфейс Workday Rhythm сейчас доступен только на русском. Пользователи с другими языковыми предпочтениями macOS должны иметь возможность пользоваться приложением на английском.

## What Changes

- Добавить русский и английский переводы пользовательского интерфейса.
- При запуске выбирать первый поддерживаемый язык в порядке предпочтений macOS. Если совпадений нет, использовать английский.
- В первой версии язык выбирает macOS через свои языковые предпочтения. Отдельный переключатель в приложении вне объёма изменения.

## Capabilities

### New Capabilities

- `interface-localization` — выбор языка интерфейса и согласованное применение перевода.

### Modified Capabilities

## Impact

Изменение затрагивает ресурсы Swift Package и слой Presentation, включая меню AppKit, настройки SwiftUI, статусы таймера и доступность. Формат сохранённой дневной программы и правила таймера сохраняются.
