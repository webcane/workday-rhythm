# Spec Delta

## Purpose

Оболочка приложения даёт пользователю доступ к Workday Rhythm через строку меню macOS, отдельное окно настроек и управляемый выход даже до появления полного таймера.

## ADDED Requirements

### Requirement: Доступность приложения после запуска
После успешного запуска приложение SHALL показывать значок Workday Rhythm в строке меню macOS и SHALL оставаться доступным для взаимодействия до команды выхода.

#### Scenario: Первый запуск каркаса
- **WHEN** пользователь запускает приложение на поддерживаемой версии macOS
- **THEN** в строке меню появляется значок Workday Rhythm с доступным меню команд

### Requirement: Открытие настроек
Приложение SHALL открывать отдельное окно настроек по команде из строки меню. Окно SHALL показывать, что параметры дневной программы появятся в следующем этапе реализации.

#### Scenario: Команда настроек
- **WHEN** пользователь выбирает «Настройки» в меню приложения
- **THEN** открывается окно настроек с временным содержимым, доступное независимо от меню

### Requirement: Выход из каркаса
Приложение SHALL завершать процесс по команде «Выход» из строки меню.

#### Scenario: Команда выхода
- **WHEN** пользователь выбирает «Выход» в меню приложения
- **THEN** процесс завершается, а значок исчезает из строки меню
